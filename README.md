# VIOX Creative Portfolio V1.2 — Brand Redesign

## Identity
VIOX means **Visuals of 10**. X is Roman numeral 10 and stands for **10/10 visual excellence**. Primary tagline: **Visuals Worth a 10.**

Premium minimalist midnight-black, champagne-gold, and ivory identity. Angular gold X logo concept. Font stack uses Montserrat / Inter with system fallbacks; no external paid assets.

## Deployment
Upload the **contents** of this folder directly to the root of your existing `ALVILZON/viox-creative-portfolio` GitHub repository on the `main` branch. Replace `index.html`, `styles.css`, `script.js`, and `README.md`; upload the `assets` folder, including SVGs. Preserve any existing resume PDF and custom project images. Cloudflare Pages will redeploy automatically.

## Customize
Edit `profile` and `projects` in `script.js` to insert your real contact information, project descriptions, and images. Put images in `assets/` and reference relative paths. Place your real PDF at `resume/resume.pdf`; the download links appear when the PDF exists. All example projects are placeholders until edited.

## Notes
Static HTML/CSS/JS, no build command, free Cloudflare Pages compatible. No analytics or external dependencies. Brand mark is SVG, not a pre-existing approved image asset; replace it if you have the exact locked logo artwork.
